Admin-Bereich

Melde dich an, um Games, Touren und Raya-Fotos zu verwalten. Änderungen werden direkt als Commit in dein GitHub-Repo geschrieben.

Wo bekomme ich den Token her?

Ein GitHub-Zugriffstoken (Personal Access Token) mit Schreibrecht auf genau dieses Repo. Anleitung zum Erstellen: ADMIN-SETUP.md im Projektordner. Der Token wird nur in deinem Browser gespeichert und nie an einen anderen Ort als api.github.com gesendet.
